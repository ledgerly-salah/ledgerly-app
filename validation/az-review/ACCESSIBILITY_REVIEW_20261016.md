## النتيجة

تم قياس 32 حالة عرض باستخدام axe-core 4.14.0، Chromium، عند عرض 390 و1440 بكسل: إعداد دفتر، الرئيسية، نموذج الدين، نموذج السداد، بطاقة دائن موسعة، والإعدادات. تتضمن الحالات الوضع الافتراضي system (فاتح في بيئة الاختبار)، والفاتح الصريح، والغامق. ليست 32 وظيفة مختلفة ولا كل حالات التطبيق.

الحالة المنشورة r11 بها مخالفات تباين مؤكدة؛ أمثلة: الرمادي #73827c على الأبيض 4.02:1، وشارة Reconciled الخضراء على خلفيتها الغامقة 2.83:1، ومبالغ صغيرة بالأحمر على الغامق 4.22:1، مقابل حد 4.5:1 الذي يطبقه الفحص لهذه النصوص.

تم تجهيز CSS مرشح في `contrast-candidate.css` لتحسين النصوص الثانوية والحالات المالية والشارات حسب الثيم. أُعيد القياس على الحالات نفسها: **32/32 حالة بدون مخالفات آلية مؤكدة ضمن القواعد المحددة**. هذا لا يغلق الإتاحة بالكامل: الأداة أعادت حالات incomplete خصوصًا النص على التدرجات والعناصر الزخرفية والتداخل. تم الاطلاع على صور الرئيسية بالموبايل في الثيمين، لكن ذلك ليس قياسًا نهائيًا لكل تلك الحالات.

لم تظهر مخالفات آلية مؤكدة لتسميات الأزرار/الحقول في الحالات المفحوصة، ولا يثبت هذا نجاح TalkBack أو الترتيب المنطقي لكل التدفقات. تجربة TalkBack على هاتف المستخدم توقفت قبل اختبار التطبيق وتظل غير مكتملة.

## حدود التغيير

المرشح ملف CSS للمراجعة، يُحمَّل بواسطة خادم الاختبار عند `LEDGERLY_A11Y_PATCH=1`. لم يتغير index.html المنشور ولا ملفات releases/r11 ولا أُنشئ إصدار منشور جديد. لم نغيّر الحساب أو التخزين أو التشفير. يلزم دمج CSS في إصدار جديد وتجربة الحزمة النهائية قبل أي نشر بإذن المستخدم؛ القياس الحالي يثبت المرشح المحمّل محليًا فقط.

النصوص داخل التدرجات، حالات التحذير/الخطأ غير الممثلة، التركيز والتحويم والتعطيل، وكل الشاشات الأخرى تحتاج إكمال التغطية قبل تسمية فحص التباين شاملًا. لا تُحسب incomplete كنجاح.

## الأدلة وإعادة التشغيل

- `accessibility-r11.json`: القياس الأصلي لكل حالة، violations وincomplete وpasses.
- `accessibility-candidate.json`: القياس بعد CSS المرشح.
- `scripts/browser-r11-accessibility.mjs`: سيناريوهات قابلة للإعادة، بيانات اصطناعية فقط. يترك 600ms قبل القياس لتجنب قياس انتقالات الظهور. يحافظ على CSP الأصلية؛ يتم تحميل أداة الفحص عبر Playwright evaluate في السياق المحلي.
- ملفات `a11y-*.png`: صور مراجعة المرشح وليست صور إنتاج.

شغّل السكريبت مع LEDGERLY_PLAYWRIGHT_MODULE وLEDGERLY_CHROMIUM_PATH وLEDGERLY_AXE_PATH (axe-core 4.14.0). أضف LEDGERLY_A11Y_PATCH=1 وLEDGERLY_A11Y_OUTPUT=validation/az-review/accessibility-candidate.json لفحص المرشح. لا تشغّل سكريبتًا آخر على المنفذ 8768 في نفس الوقت.
